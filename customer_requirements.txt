Customer Requirements (Point Wise)

1. Production Planning Automation

• System should automatically generate production plans.

• Planning should be based on machine capacity matrix.

• Consider available manpower and machine availability.

• Generate machine-wise production schedules.

• Generate shift-wise production plans.

• Reduce dependency on manual Excel planning.

2. Daily Production Plan & Output Tracking

• Capture daily production targets.

• Record actual production output.

• Compare Planned vs Actual production.

• Generate date-wise production reports.

• Generate shift-wise production reports.

• Track production performance daily.

3. Production Monitoring

• Monitor production machine-wise.

• Monitor department-wise production.

• Maintain centralized production database.

• Track historical production records.

• View real-time production status.

• Measure machine utilization and productivity.

4. Backlog and Carry Forward Order Management

• Track pending production orders.

• Track blocked orders.

• Generate carry-forward order reports.

• Identify delayed orders.

• Monitor order completion status.

• View backlog quantity and backlog trends.

5. Machine Utilization Monitoring

• Track machine-wise utilization percentage.

• Compare standard output vs actual output.

• Monitor machine efficiency.

• Identify under-utilized machines.

• Analyze production bottlenecks

6. Downtime Management

Customer currently tracks various production loss reasons and wants better visibility.

Examples observed in the existing process include:

• Maintenance downtime

• Power failure downtime

• Material shortage

• Material handling delays

• Operator absence

• Manpower rescheduling

• Operator inefficiency

• Unscheduled stoppages

• Required:

• Capture downtime reasons digitally.

• Measure downtime hours.

• Analyze loss reasons.

• Generate downtime reports.

7. Machine Maintenance Management

• Machine master management.

• Preventive maintenance scheduling.

• Breakdown maintenance tracking.

• Maintenance history records.

• Maintenance alerts and reminders.

• Machine health monitoring.

• Maintenance KPI reports. [DAY WISE O...T-2026 (2) | Excel]

8. Production Resource Management

• Track manpower deployment.

• Compare standard manpower vs actual manpower.

• Track operator shortage.

• Monitor manpower utilization.

• Measure impact of manpower availability on production.

9. Production Analytics & Dashboards

Management requires dashboards for:

• Production achievement %

• Machine utilization %

• Downtime %

• Productivity analysis

• Department performance

• Shift performance

• Production trends

• Capacity utilization

• Order backlog analysis

• Maintenance performance

10. Alerts & Notifications

System should provide alerts for:

• Machine breakdown

• Excess downtime

• Production target not achieved

• Maintenance due

• Material shortage

• Critical backlog

• Delayed orders

11. ERP 10.8 Integration

The new solution must integrate with ERP 10.8 and exchange data automatically.

Data expected from ERP:

• Sales Orders

• Work Orders

• Item Master

• BOM

• Customer Master

Data expected back to ERP:

• Production output

• Production completion status

• Order progress

• Maintenance information

• Daily Production Report

• Machine Utilization Report

• Production Output Summary

• Downtime Report

• Backlog Report

• Carry Forward Order Report

• Maintenance Report
